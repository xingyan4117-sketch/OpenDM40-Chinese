## 说明书怎么读

按使用场景分：

- 刚拿到表 → 第 1~3 章（这是什么、安装升级、开机界面）
- 日常测量 → 第 4~9 章（万用表、量程、REL、MAX/MIN、趋势图）
- 示波器 → 第 10~11 章
- 信号源 → 第 12 章
- 功率计 / 涌流 → 第 13~14 章
- 记录、截图、图库、U 盘 → 第 15~16 章
- 设置项 → 第 17 章（24 项的逐条说明）
- 电脑远程控制（SCPI）→ 第 18 章
- 出事怎么办 → 第 19~20 章（备份、救砖、回退、关机后保留什么）
- 已知限制 → 第 21 章
